## Description

SMS Número Virtual is a platform that allows receiving SMS messages online using virtual phone numbers. Ideal for verifying accounts on services without exposing your personal number.

### Main Features

- **Numbers from multiple countries**: Available in 50+ countries
- **Real-time reception**: SMS arrive instantly
- **No registration required**: Use public numbers without creating an account
- **API available**: Integrate the service into your applications
- **Privacy guaranteed**: We don't store your personal data

### Technologies Used

The project is built with modern technologies:

- **Frontend**: Next.js 16 with App Router
- **Styles**: Tailwind CSS for responsive design
- **Backend**: Supabase
- **Database**: PostgreSQL for number storage
- **E-mail**: Resend SMTP
### Project Status

This project is under active development. New numbers and features are added regularly.
