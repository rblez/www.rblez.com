## Descripción

SMS Número Virtual es una plataforma que permite recibir mensajes SMS en línea usando números de teléfono virtuales. Ideal para verificar cuentas en servicios sin exponer tu número personal.

### Características principales

- **Números de múltiples países**: Disponible en 50+ países
- **Recepción en tiempo real**: Los SMS llegan instantáneamente
- **Sin registro requerido**: Usa números públicos sin crear cuenta
- **API disponible**: Integra el servicio en tus aplicaciones
- **Privacidad garantizada**: No almacenamos tus datos personales

### Tecnologías utilizadas

El proyecto está construido con tecnologías modernas:

- **Frontend**: Next.js 16 con App Router
- **Estilos**: Tailwind CSS para diseño responsive
- **Backend**: Supabase
- **Base de datos**: PostgreSQL para almacenamiento de números
- **Email**: Resend SMTP

### Estado del proyecto

Este proyecto está en desarrollo activo. Se agregan nuevos números y funcionalidades regularmente.
