Este es mi primer post usando el nuevo sistema de **writing** con Velite.

## Cómo funciona

1. Escribo en MDX en la carpeta `content/blog/`
2. Ejecuto `pnpm build`
3. Velite convierte el MDX a HTML
4. El script genera páginas estáticas en `writing/`

## Código de ejemplo

```javascript
const greeting = "Hello World";
console.log(greeting);
```

El sistema genera HTML puro sin necesidad de un framework de frontend. Perfecto para un blog simple y rápido.
