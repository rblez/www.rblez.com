Name:        rblez-blog

License:     All Rights Reserved

================================================================================
ROUTE STRUCTURE
================================================================================

/                 → Redirects to /me
/me               → Personal page (bio, avatar, social links)
/stack            → Tech stack showcase with filters
/blog             → Blog posts listing
/blog/[slug]      → Individual blog post
/not-found        → Custom 404 page

================================================================================
TECHNICAL STACK
================================================================================

FRAMEWORKS:
  - Next.js 16.2.1 (App Router, Turbopack)
  - React 19.2.4
  - TypeScript 5.x

STYLING:
  - Tailwind CSS v4
  - Custom CSS with font-face declarations
  - Dark mode via system preference

CONTENT:
  - Velite 0.3.1 (MDX content collection)
  - MDX 3.1.1
  - Rehype plugins (syntax highlighting, autolink headings)

ICONS:
  - @icons-pack/react-simple-icons 13.13.0
  - RemixIcon 4.9.1

FONTS:
  - CursorGothic (Regular, Bold) - Primary
  - BerkeleyMono (Regular) - Monospace

DEPLOYMENT:
  - Vercel (Serverless, Edge Network)

DESIGN SYSTEM
================================================================================

COLOR PALETTE:
  Light Mode:
    Background: #ffffff
    Foreground: #000000
    Primary: #000000
    Secondary: #f5f5f5
    Muted: #737373
    Border: #e5e5e5

  Dark Mode:
    Background: #000000
    Foreground: #ffffff
    Primary: #ffffff
    Secondary: #262626
    Muted: #a3a3a3
    Border: #404040

TYPOGRAPHY:
  Primary Font: CursorGothic
    - Regular (400)
    - Bold (700)
  
  Monospace Font: BerkeleyMono
    - Regular (400)

  Fallback: -apple-system, BlinkMacSystemFont, SF Pro

EFFECTS:
  - Liquid background orbs (blur: 100-120px)
  - Backdrop blur for glass effect
  - Scale hover animations (1.05-1.10)
  - Smooth transitions (duration: 200-300ms)
  - Subtle borders (opacity: 5-10%)

================================================================================
CONTENT MODEL (Blog Posts)
================================================================================

Frontmatter Fields:
  - title (string, required)
  - description (string, required)
  - date (string, required, ISO format)
  - published (boolean, default: false)
  - slug (auto-generated from filename)

Example:
  ---
  title: "My First Post"
  description: "A brief description"
  date: "2026-01-15"
  published: true
  ---
