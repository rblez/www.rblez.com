# AGENTS.md — www.rblez.com

Personal site of rblez (software engineer, Santiago de Cuba). One clean page per language: who he is in one line, the two main projects (Tiendly and Pickea) with their official isotypes and real mobile previews, a short "more things" list and links. Redesigned 2026-11-16.

## Stack

- **Deploy**: Cloudflare Workers static assets (`wrangler.jsonc`, `assets.directory: "."`); every push to `master` deploys. No Worker script.
- **No build step, no package.json, no frameworks.** Inline CSS, one tiny inline script (theme switch). No third-party requests.
- **Generator**: `es/index.html` and `en/index.html` are generated by `python3 rblez-gen.py` (single template + ES/EN strings). Edit the generator, then run it; never edit one language by hand.

## Look (Ray's identity)

- Cream `#f7f7f4` bg, ink `#26251e`, muted ink (~64% alpha); dark `#14120b` / `#edecec`. Accent orange `#f54e00` (dark `#ff6a1f`, as rblez/ui `--d-brand`), text on accent `#14120b`.
- Subtle grain: `/img/noise-l.webp` (light) / `/img/noise-d.webp` (dark) as body background, 96px tile. Mandatory in Ray's designs; keep it subtle.
- Font: Inter 600–700 subset, self-hosted `/fonts/inter-sub.woff2` (OFL, `fonts/Inter-OFL.txt`). The subset has no ↗ etc.; use inline SVG for arrows. Never self-host SF Pro.
- Isotype `/isotipo.svg` (black, CSS-inverted in dark) top-left. No name text visible; JSON-LD Person name is "rblez".
- Theme switch in footer (dark/light/auto, Iconoir icons, MIT), `localStorage.theme`, `html[data-theme]`; otherwise `prefers-color-scheme`.

## SEO

Per-language canonical, description, OG/Twitter (`/og-image.jpg`, 1200×630), `og:locale` + alternate, hreflang (es, en, x-default → /). JSON-LD @graph: WebSite + WebPage + Person (founder of Tiendly and Pickea). `index.html` at the root redirects by browser language to /es/ or /en/ (noindex). `.assetsignore` keeps AGENTS.md, wrangler.jsonc and rblez-gen.py out of the public site.

## Sub-apps (do not break)

- /ui/ = build of rblez/ui (apps/preview, vite base /ui/). Copy apps/preview/dist/* to ui/ when it changes. Never touch it from the home page work.
- /asciidot/ = build of rblez/asciidot (vite build --base=/asciidot/); /terminal/ = rblez/terminal-web rblez.html; /explorador/ = copy of rblez/explorador-tarjetas-cubanas.

## Constraints

- `assets.directory` is `"."`: everything in the repo root is public; keep secrets out.
- Responsive from 360px; respect `prefers-reduced-motion`. `isotipo.svg` stays black (#000); only the favicon has a white variant.
